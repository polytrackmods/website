How to play

Web

To play with PolyModLoader in the web, simply visit web.polymodloader.com in a web browser. The web version works on both Desktop (Windows, MacOS, Linux etc.) and Mobile (iOS, Android, etc.) environments.


App

To play with PolyModLoader on the App, go to the codeberg releases page and download the version for your OS. You can also download the app.asar and replace the app.asar in an existing PolyTrack or PolyModLoader installation. Currently only Windows, MacOS and Linux are supported. An Android app version is currently being tested.
